ABOUT THE PROJECT

RowGlide adds drag-and-drop ordering to two familiar Minecraft screens: your multiplayer server list and your resource-pack selection. It is a client-side Fabric mod built around moving the row itself, so putting a favorite server at the top or changing pack priority feels like one direct action.

01

Your multiplayer list, in your order.

Click and hold the text area of a server row, move it up or down, and release it where you want it. The server box follows the pointer vertically while staying inside the list, so you can see the position you are choosing.

The new server order is written to Minecraft's servers.dat when the drop is committed. Long lists auto-scroll when you drag near their top or bottom edge, letting you move a row farther than the currently visible entries.

02

Selected packs, sorted your way.

Resource-pack priority is controlled by the order of the Selected list. RowGlide lets you change that order by dragging the pack's text area, rather than repeatedly using the usual arrow controls.

You can also drag a pack between the Available and Selected columns. A destination gap shows where the drop will go, and the change is committed when you release the mouse.

What can move?
ListRowGlide behavior
Multiplayer serversDrag rows to reorder your saved servers.
Selected resource packsDrag rows to change pack priority.
Between pack columnsTransfer a pack into or out of Selected.
Available resource packsNormal Minecraft ordering is retained.
Singleplayer worldsNormal Minecraft behavior; worlds are not draggable.
03

The familiar controls stay familiar.

Dragging starts from a row's text area. The icon area keeps its ordinary join, enable, disable, and arrow actions, so the new interaction sits alongside the controls you already know.

The Available resource-pack column is deliberately not a freely reorderable list. A pack dropped back there returns to its normal Minecraft position. Dragging is also disabled while the resource-pack search box is filtering results, keeping the visible filtered list separate from the underlying order.

04

Start with the right Fabric profile.

Install the RowGlide file for your Minecraft version in the mods folder of your Fabric client. It does not need to be installed on the server you join.

  1. Choose a matching release.

    Published Minecraft versions include 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, and 26.3. Use the release matching your instance.

  2. Open a supported list.

    Go to Multiplayer, or open Minecraft's resource-pack selection screen.

  3. Drag the text, then release.

    Hold a row by its text area, move it to the new position, and release the mouse to commit the change.

Good to know

The project README specifies Fabric Loader 0.19.3 or newer, and 0.19.5 or newer for Minecraft 26.3. The Modrinth Versions tab is the place to check individual release details.
