ABOUT THE PROJECT

QuitKeybind gives leaving a Minecraft world a dedicated key. Instead of opening the pause menu and choosing the disconnect button, press your chosen key to use Minecraft's normal exit process. It works for multiplayer servers and singleplayer worlds, with the mod installed on your client.

01

A shortcut to Minecraft's own exit.

The keybind runs Minecraft's native disconnect flow. It is a shortcut to leaving the world, rather than a separate way of handling world saves or server disconnections.

The Minecraft application stays open. The key is for leaving the current server or world; it is not an operating-system shortcut to force-close the game.

The same key, two familiar exits
Where you are playingWhat the key does
MultiplayerDisconnects you from the current server through the native client flow.
SingleplayerLeaves the world through Minecraft's normal save-and-exit flow.
02

Make the key yours.

F8 is assigned by default, but the binding lives in Minecraft's Controls menu. If that key is already used by your setup, choose another one in the QuitKeybind entry.

  1. Open Key Binds.

    In Minecraft, open Options, then Controls, then Key Binds.

  2. Find QuitKeybind.

    Select its binding and assign the key you want to use.

  3. Use it in a world.

    While connected to a server or playing a singleplayer world, press the assigned key to leave.

03

Install it where you play.

QuitKeybind is fully client-side. The server does not need it, and it works in Fabric instances created through the Modrinth App as well as other Fabric client installations.

Download the file matching your Minecraft version and place it in that client instance's mods folder. Use the release instructions for its dependencies rather than mixing files intended for different Minecraft versions.

  • Published files cover Minecraft 1.21.11 and the 26.1, 26.1.1, 26.1.2, 26.2, and 26.3 releases.
  • The project supports Mod Menu, where it appears with its name, icon, and project information.
  • It is a Fabric client mod, not a plugin for a server's plugins folder.
04

Keep a quick exit within reach.

The mod focuses on one small action: leaving the current world with a key you choose. The published feature list includes configurable keybinding, native disconnect handling, Mod Menu support, and Modrinth App compatibility.

For the current file, supported game version, and release requirements, use the official Modrinth listing. Periklis20M and JohnFG develop and test the project together.
