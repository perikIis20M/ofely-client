ABOUT THE PROJECT

bwhitelist, also described as BetterWhitelist, is a server plugin for managing who may join. It focuses on player matching and everyday whitelist commands: handling case differences, adding offline players, and offering useful suggestions when administrators add or remove a name.

01

A more practical player list.

The published features include case-insensitive username matching and adding offline players to the whitelist. These address the friction of managing names and the familiar Player does not exist limitation described by the project.

Tab completion supports the command workflow: adding players suggests online names, and removing players suggests names already on the whitelist. The aim is to make maintaining the list more direct for server administrators.

02

Four commands for the daily work.

The /bwhitelist command is the entry point for adding, removing, inspecting, and reloading the list.

The documented administrative permission is betterwhitelist.admin, available to operators by default. This gives administrators a specific permission to check when assigning access to whitelist management.

Whitelist commands
CommandPurpose
/bwhitelist add <player>Add a player to the whitelist.
/bwhitelist remove <player>Remove a whitelisted player.
/bwhitelist listDisplay the current whitelist.
/bwhitelist reloadReload the whitelist.
03

Choose matching and save behavior.

config.yml controls case-insensitive matching and automatic saving. The documented example enables both and sets the automatic save interval to 300 seconds.

Messages are kept separately in messages.yml. They include the join rejection message, permission errors, add/remove confirmations, duplicate or missing-player responses, and the reload confirmation. Those messages can be adjusted to match the language and tone of your server.

YAML / DOCUMENTED EXAMPLE
case-insensitive: true
auto-save: true
auto-save-interval: 300
04

Install it as a server plugin.

Download a compatible release, place the JAR in the server's plugins directory, and restart. The project lists Bukkit, Purpur, and Spigot releases for selected Minecraft versions from 1.19.1 through 1.21.7.

Use the Versions tab to match a file to your actual server software and game version. This is a server-side whitelist tool, so players do not need a separate client installation.
